# In-house model evidence review — 2026-09-25

This review uses certified team pregame snapshots and immutable player-prop
publication snapshots. The scorecard is regenerated by `scripts/inhouse_model_scorecard.py`
after grading, with the prospective boundary fixed at 2026-09-22 00:00 UTC.
Each row is split by fitted version and market. Only observed, timestamped,
pregame American prices enter financial results. Event-clustered bootstrap
intervals account for multiple picks on one game. PASS forecasts remain visible
and settle for research; a separately reported shadow return never counts as a
placed bet.

## Decision

No fitted version and market is approved for staking. The only historical
segment with at least 100 priced settled picks and a positive clustered lower
bound is one MLB full-game totals version (120 picks, +39.5% ROI, +13.8% lower
bound, 35 event clusters). Its dates were inspected while selecting earlier
MLB rules, so it is ineligible as an untouched final holdout. The current
approval file is intentionally empty. Every unapproved in-house BET/LEAN is
published as PASS at 0 units, with its proposed decision and stake retained
as `shadow_decision` and `shadow_units` for prospective grading.

The 961 version/market scorecards contain 1,414 priced settled bets in total,
but pooling those bets would hide changing fitted artifacts and decision
rules. In particular, MLB player props span 371 fitted fingerprints and WNBA
props span 129, leaving most versions with tiny independent samples. Routine
player-prop refreshes now evaluate a consensus candidate without replacing
the active artifact. An approval must name an exact fitted version, market,
variant, frozen rule, and reviewed final holdout with at least 100 independent
priced settled picks, positive ROI and positive 95% clustered lower bound, and
no material calibration regression.

## Reproduction and limits

Run `.venv/bin/python scripts/inhouse_model_scorecard.py --output /tmp/inhouse-model-scorecard.json`.
The scheduled grader uploads the same report as an Actions artifact. The
scorecard compares model and observed market probabilities on paired settled
games when both probabilities exist; it does not fill missing prices or infer
what a sportsbook offered. The September 22 boundary stays fixed, but results
since that date are not automatically untouched because earlier work inspected
some of those dates. Before any approval, freeze the candidate implementation
and rule, designate a later unused chronological window, replay features as
of game time, compare incumbent and challenger on identical games and quotes,
and review both financial and calibration results.
